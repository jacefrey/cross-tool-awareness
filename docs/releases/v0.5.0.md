## What this release is

Phase 2b pre-live hardening of CTA against process-contention and legacy owner-less entry points. Full change set in `CHANGELOG.md` §0.5.0. Design authority: `codex-manager/docs/superpowers/specs/2026-10-14-awareness-pre-live-hardening-design.md` (revision tip `abc1864`, MM-approved at bridge seq 343).

Requirements implemented in this release:
- **R1** (safety envelope — no live code paths touched)
- **R2** (immutable release; v0.5.0 ≠ v0.4.0 amendment)
- **R3** (owner tuple on `targeted_deliveries`)
- **R4** (dispatch_ownership witness; no GC; rollback refusal on unmatched)
- **R5** (owner-aware API with required claimant kwargs; dispatcher + probe fail-close)
- **R6** (BEGIN IMMEDIATE package ownership; reject nested caller transactions)
- **R7** (+/- 30 s freshness window at mark boundary)
- **R8** (contention + no time-recovery of `dispatching`)
- **R9** (quiescent-only v3→v4 migration; preserve state unchanged on refusal)

R10–R14 remain B-plan territory and are CXM-owned (CLI amendment, policy migration, bootstrap evidence, integrated verification, live packet).

## Migration from v0.4.0 call sites

### Constructing a `CompositeStorage`

**v0.4.0:**
```python
facade = CompositeStorage(db, tool="claude", wake_capability="notify_only")
```

**v0.5.0:** owner identity + clock injected at construction, immutable for the facade's lifetime.
```python
from cross_tool_awareness import ClaimantIdentity, CompositeStorage
import time

claimant = ClaimantIdentity(
    session_uuid=my_session_uuid,
    session_incarnation_id=my_incarnation_uuid,
    registration_fence=my_registration_fence,
)
facade = CompositeStorage(
    db, tool="claude", wake_capability="notify_only",
    claimant=claimant, clock=lambda: int(time.time()),
)
```

### Claiming a delivery

**v0.4.0:**
```python
claim = facade.claim_delivery(now=now, recovery_after=30)
```

**v0.5.0:** caller supplies a `RegistrationSnapshot` carrying a fresh positive OS observation of its own liveness.
```python
from cross_tool_awareness import RegistrationSnapshot
snapshot = RegistrationSnapshot(
    presence=my_presence_record,
    holder_pid=os.getpid(),
    process_started_at=my_process_started_at,
    proof_observed_at=int(time.time()),
)
claim = facade.claim_delivery(
    now=now, recovery_after=30,
    claimant_snapshot=snapshot,
)
```

### Marking dispatching + writing the witness

**v0.4.0:**
```python
ok = facade.pre_adapter_mark(claim, now, lease_token=claim.claim_lease_token)
```

**v0.5.0:** caller supplies BOTH the claimant snapshot AND the target snapshot (fresh OS observations of each registration's liveness). The witness is written atomically with the state change inside the same `BEGIN IMMEDIATE` transaction.
```python
ok = facade.pre_adapter_mark(
    claim, now,
    lease_token=claim.claim_lease_token,
    claimant_snapshot=my_snapshot,
    target_snapshot=target_snapshot,
)
```

### Finalizing an attempt

The facade signature is unchanged from v0.4.0:
```python
receipt = facade.finalize_attempt(claim, attempt, lease_token=claim.claim_lease_token)
```

But the underlying `leases.finalize_attempt` now authenticates against the `dispatch_ownership` witness: a wrong owner / wrong token / wrong key call returns `FinalizationResult(status="unauthorized")` with zero rows changed. The facade's internal result → return value mapping is preserved.

### Direct `leases.*` callers

All public writers (`claim_delivery`, `pre_adapter_mark`, `pre_adapter_release`, `finalize_attempt`) now require `claimant: ClaimantIdentity` and `clock: Callable[[], int]` kwargs. Missing kwargs raise `TypeError`.

Entry points own `BEGIN IMMEDIATE` transactions and reject an active caller transaction with `sqlite3.ProgrammingError`. Callers that previously wrapped these calls in `with db:` must remove the outer transaction.

### Disabled callables

`dispatcher.run_one_iteration` and `probe.run_foreground_probe` raise `RuntimeError('legacy dispatcher disabled: claimant-aware bounded runner required')` on every call. Existing call sites must be removed; a replacement claimant-aware bounded runner is deferred to a later roadmap gate.

## Not in this release

- No live code paths touched. The safety envelope (design R1) still holds.
- No CLI amendment. The pinned exact build (`codex-cli 0.149.0-alpha.4.1`) still bounds delivery; installed `0.162.0-alpha.17.2` is NOT recognized. See CXM B1 for the pre-live CLI amendment plan.
- No policy migration. Current policy forbids live dispatcher paths; a narrow allowance for the bounded foreground path requires CXM B2 (trusted-runtime evidence) and B3 (policy review) first.
- No merge, no tag push, no publish. This release freezes the candidate for independent review.
